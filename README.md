# MC LEGEND - RP GRIND GAME v1.0 💸

A text-based RP game where you grind from broke to $2000.

Made by: **MC LEGEND**

---

## 🎮 How To Play

Start with $300 and grind your way to **$2000** to win.

- **Work** to earn money (costs energy)
- **Fight** to rob people (raises wanted level)
- **Manage** your HP, Energy, and Wanted
- **Join** organizations for team grind

## 🕹️ Controls

| Key | Action |
|-----|--------|
| 1 | Inventory |
| 2 | Find Work |
| 3 | Fight NPC |
| 4 | Work Job |
| 5 | Shop |
| 6 | Quit / Delete Save |
| 7 | Organization |
| 8 | Sleep (Restore Energy) |

## ⚡ Systems

- **Energy System:** Work 5x = tired, must sleep
- **Wanted System:** 0-3 stars, 3 = police after you
- **HP System:** Die if 0 HP, buy medkits in shop
- **Save System:** Auto saves your progress

## 🏆 Win / Lose

**WIN:** 
-Reach $2000 = VICTORY

**LOSE:** 
- HP = 0 = Dead
- Wanted = 3 = Busted
- Arrested by cops
